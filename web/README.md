# Atrium — Web (React + Vite)

Тёмный минималистичный веб-клиент корпоративного мессенджера Atrium.
Стек: **Vite + React 18 + TypeScript**, `react-router-dom`, `socket.io-client`,
ручной CSS без UI-фрейморков (токены из `SPEC.md`, раздел 1), шрифт Inter с Google Fonts.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (прокси /api и /socket.io → http://localhost:4000)
npm run build      # production-сборка (tsc + vite build, 0 ошибок TS)
npm run typecheck  # только проверка типов
```

Бэкенд (порт 4000) должен быть запущен отдельно — см. корневой `README.md`.

## Возможности

- Вход / регистрация (токен в `localStorage` `atrium_token`, авто-logout при 401)
- Организации: переключатель, создание, описание, выход из организации
- Каналы и личные сообщения (DM), создание каналов при ранге ≥ 40
- Чат: группировка по датам, свои сообщения справа с акцентной заливкой,
  действия по наведению (удаление — автор или ранг ≥ 60), индикатор печати,
  «Загрузить ещё» при прокрутке вверх, автопрокрутка вниз
- Правая панель: участники с ролями и меню смены роли (матрица прав SPEC §2),
  исходящие приглашения с отменой, информация об организации (редакт. ранг ≥ 60)
- Входящие приглашения: подписанный **договор** + canvas-поле подписи
  (указание ФИО ≥ 2 символов, росчерк обязательно) → «Подписать и вступить»
- Звонки 1:1 (WebRTC, STUN Google): входящая модалка с пульсацией,
  полноэкранный разговор (большое видео собеседника, зеркальный pip),
  микрофон / камера / смена камеры / завершение, статус соединения
- Realtime через Socket.IO: `message:new`, `typing`, `invite:new`,
  `member:joined/left`, `role:changed`, `channel:created`, `presence:update`

## Структура

```
src/
  api.ts            — типизированный fetch-обёртка (Bearer, авто-logout на 401)
  socket.ts         — singleton Socket.IO + emitAck с таймаутом
  types.ts          — типы и нормализация фигур SPEC (в т.ч. неоднозначность `{user}`)
  permissions.ts    — матрица прав из SPEC §2 (только для отображения UI)
  store.tsx         — глобальное состояние приложения (организации, чаты, тосты)
  hooks/useWebRTC.ts— состояние звонка и вся сигнализация WebRTC (SPEC §4)
  components/       — Sidebar, ChatPane, RightPanel, InvitesScreen, SignaturePad,
                      CallOverlay, CallProvider, модалки, иконки
  pages/            — Login, Register
```

## Ограничения (из SPEC)

- Звонки одиночные (1:1), без TURN — за симметричных NAT связь может не установиться
- Нет загрузки файлов, нет счётчиков непрочитанного (опционально)
